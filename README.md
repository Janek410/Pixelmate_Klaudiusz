# PixelMate (Python / PySide6)

## PyCharm
1. File → Open → wybierz folder `pixelmate_py`.
2. Settings → Project → Python Interpreter → Add Interpreter → New (Virtualenv), Python 3.9+.
3. PyCharm zaproponuje instalację z `requirements.txt` (albo w terminalu: `pip install -r requirements.txt`).
4. Prawy klik na `main.py` → Run 'main'.

Pet spada z góry ekranu. Menu: prawy klik na peta albo ikona w zasobniku systemowym.
Ustawienia zapisują się w `settings.json`. Zamknięcie: menu → Zamknij (albo Stop w PyCharmie).

Sterowanie: klik = głaskanie, dwuklik = skok, przeciągnij i puść/machnij = rzut.
